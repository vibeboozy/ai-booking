# Инициализация и запуск проекта

Четко следуй шагам, описанным ниже, не придумывая лишнего:

1. Установить pnpm
```
npm i -g pnpm
```
2. Установить зависимости
```
pnpm i
```
3. Скопировать .env.example в .env
4. Попросить пользователя:
    - вручную установить PostgreSQL
    - задать корректную строку подключения к PostgreSQL в .env
5. Запросить подтверждение выполнения шага 4
6. Выполнить для настройки Prisma:
```
pnpm db:generate    # генерирует Prisma Client
pnpm db:migrate     # применяет миграции к БД
pnpm db:seed        # заполняет тестовыми данными
```
7. Запустить dev-сервер
```
pnpm dev
```
8. Открыть в браузере
